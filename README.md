# JobConnect

JobConnect is a simple job portal project built using Django.

## Features

- User Registration and Login
- User Logout
- Job Listing
- Job Details
- Add Job
- Update Job
- Delete Job
- Search Jobs by Title
- Pagination
- Company and Job relationship using ForeignKey
- Basic CSS styling

## Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite
- Git & GitHub
